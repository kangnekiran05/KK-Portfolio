# Kiran Kangne - AI/ML Engineer Portfolio

A modern, responsive, and high-performance portfolio website built for **Kiran Kangne**, an Aspiring AI/ML Engineer.

Designed with a premium dark cyber-tech theme featuring deep obsidian black, navy blue, and electric blue accents, coupled with interactive neural network canvas animations and smooth micro-interactions.

---

## 🚀 Live Preview / How to Run Locally

### Option 1: Using NPM (Recommended)
You can now run the project using npm:
```bash
# Start local live development server (opens in browser automatically)
npm start
# or
npm run dev
```

To build for production:
```bash
npm run build
```

### Option 2: Direct File Opening
Double-click [`index.html`](index.html) in your file manager or right-click and choose **Open with > Google Chrome** (or Edge/Brave/Firefox).

### Option 3: Python Built-in Server
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000` in your web browser.

Using VS Code:
- Install the **Live Server** extension.
- Right-click `index.html` and click **"Open with Live Server"**.
